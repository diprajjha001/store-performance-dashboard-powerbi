# 🛍️ Store Performance Dashboard | Power BI Project

An interactive **Power BI Store Performance Dashboard** designed to analyze retail sales performance, monitor KPIs, track product growth trends, and provide actionable business insights through data visualization.

---

# 📌 Project Overview

This dashboard helps businesses monitor overall store performance by analyzing:

- Total Revenue
- Total Orders
- Average Order Value (AOV)
- Sold Products
- Product Category Performance
- Monthly Product Trends
- Sales Growth Metrics

The project focuses on transforming raw retail data into meaningful insights using **Power BI**, **DAX**, and modern dashboard design techniques.

---

# 🎯 Project Objective

The objective of this project is to build a modern and interactive retail analytics dashboard that:

- Tracks store performance KPIs
- Identifies monthly sales trends
- Monitors product category growth
- Helps businesses make data-driven decisions
- Improves reporting and performance analysis

---

## 🔹 KPI Cards

# 📈 KPIs Used

### Total Revenue
Measures total sales revenue generated.

### Total Orders
Tracks the total number of customer orders.

### Average Order Value (AOV)
Calculates average revenue generated per order.

### Total Sold Products
Shows the total quantity of sold products.

### Product Growth %
Analyzes month-over-month product sales growth.
